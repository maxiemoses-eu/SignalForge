Once we established the core architecture for SignalForge, the real challenge began with building our automated integration pipeline. We wanted to enforce a strict security as code philosophy, which meant integrating secret scanners, dockerfile linter tools, and vulnerability checkers directly into our GitHub Actions. However, our initial deployments threw a massive wrench in our plans when the pipeline crashed during registry pushes. We discovered that the GitHub Container Registry strictly forbids uppercase letters in repository paths. Since our project name contains capitals, pulling the repository name directly into our container tags caused the registry to reject our images entirely. Rather than pulling in bulky third party formatting actions, we solved this by injecting standard bash parameter expansion to lowercase the variables natively inside the runner environment. Finding clean, native solutions to keep our automated pipelines lightweight and dependency free has been incredibly rewarding.
